# 🌐 My Portfolio

Welcome to **My Portfolio** — a personal portfolio website designed to showcase my skills, projects, experience, and journey as a **Backend Developer**.

The portfolio provides an overview of my technical skills, featured projects, and ways to connect with me. It was built with a focus on **clean design, responsiveness, accessibility, and a smooth user experience**.

🚀 **View the live portfolio:**

## 🖥️ About the Project

This portfolio website serves as my personal online presence and a central place where recruiters, collaborators, and other developers can learn more about me and explore my work.

It includes:

* 👨‍💻 **About Me** — An introduction and overview of my background
* 🛠️ **Skills** — Technologies and tools I work with
* 📂 **Projects** — Selected projects showcasing my development experience
* 📄 **Resume** — Option to view or download my resume
* 📞 **Contact** — Easy ways to get in touch with me
* 🔗 **Social Links** — Links to my professional platforms and profiles

The website was designed to provide a **simple, modern, responsive, and user-friendly experience** across different screen sizes.

## 🚀 Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/benbash/myPortfolio
```

### 2. Navigate into the project folder

```bash
cd my-portfolio
```

### 3. Open the project

Open `index.html` in your browser, or use **Live Server** in Visual Studio Code for a better development experience.
